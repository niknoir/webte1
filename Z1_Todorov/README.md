# Mykola Todorov — Osobná webová vizitka

**Meno:** Mykola Todorov  
**Krúžok / skupina:** FEI STU — Aplikovaná informatika, 3. ročník

## Odkaz na stránku

> Stránka je určená na lokálne spustenie. Pre školský server: *bude doplnené po nasadení.*

## Obsah webu

Osobná webová vizitka pozostávajúca z piatich podstránok:
1. **index.html** — Profil: krátke predstavenie, kľúčové zručnosti, motto
2. **pages/cv.html** — Životopis: vzdelanie, zručnosti (skill bars), jazyky, kontakt
3. **pages/workspace.html** — Pracovné prostredie: interaktívny obrázok s hotspotmi (CSS hover/focus)
4. **pages/schedule.html** — Rozvrh: tabuľka 7–21 hod., filter Prednášky/Cvičenia, postup semestra
5. **pages/map.html** — Mapa: Leaflet.js, vlastné body, Haversinova vzdialenosť, localStorage
